# Projeto Final — Análise de Investimentos Financeiros e Variação de Moedas

## Sobre o projeto

Este projeto foi desenvolvido como trabalho final do curso de Python, com o objetivo de analisar dados financeiros e econômicos utilizando a linguagem Python e suas bibliotecas.

A análise utiliza uma base de dados com 50.000 registros, incluindo cotações de moedas estrangeiras e indicadores macroeconômicos, abrangendo o período de 2003 a 2022.

## Objetivos

- Explorar e organizar uma base de dados financeiros.
- Identificar problemas de qualidade e valores ausentes.
- Calcular cotações médias e variações percentuais.
- Comparar o comportamento histórico de diferentes moedas.
- Analisar a volatilidade e os riscos cambiais.
- Relacionar indicadores macroeconômicos com a variação do dólar.
- Criar gráficos para facilitar a interpretação dos resultados.
- Identificar moedas com maior estabilidade e maior risco em um período de cinco anos.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- PyCharm
- Git e GitHub

## Principais análises realizadas

1. Exploração inicial dos dados.
2. Qualidade e tratamento dos dados.
3. Mapeamento das moedas.
4. Análise das cotações médias.
5. Identificação de máximas e mínimas.
6. Cálculo da variação percentual acumulada.
7. Comparação histórica entre moedas.
8. Análise de volatilidade.
9. Comparação com indicadores macroeconômicos.
10. Representação gráfica dos resultados.
11. Estudo aplicado sobre estabilidade e risco cambial.

## Resultados

O projeto permitiu identificar diferenças significativas entre as moedas analisadas, tanto em relação à valorização acumulada quanto à volatilidade histórica.

Também foram desenvolvidas visualizações para facilitar a comparação entre as moedas e apoiar a interpretação dos resultados financeiros.

## Como executar o projeto

1. Instale o Python.
2. Instale as bibliotecas necessárias:

```bash
pip install pandas matplotlib
```

3. Abra o projeto no PyCharm.
4. Certifique-se de que o arquivo `investimentos.csv` esteja na mesma pasta do arquivo Python.
5. Execute o arquivo `Analise_Investimento_Financeiro.py`.
